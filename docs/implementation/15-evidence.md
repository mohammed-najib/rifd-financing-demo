## Repayment presentation

The owning applicant and submitted staff viewer can open the dedicated
`/applications/:id/repayment` and `/staff/applications/:id/repayment` routes.
Approved detail links to the overview. Other states replace the route with
permitted detail and an explanation. Staff navigation retains the queue query.
Missing and forbidden destinations use the existing neutral unavailable screen;
unsigned links resume only for an identity permitted to read the application.

The overview reads the existing frozen snapshot through `Demo.readApplication`.
It shows accepted amount, markup and total separately, derives Completed and
remaining amounts by summing stored row statuses, and selects the first stored
Upcoming entry as the next installment. It displays the approval date, term and
every dated installment with translated Gregorian months, Western digits and
whole-YER currency labels. The fictional, read-only explanation stays visible.
There are no payment or completion commands, schema changes or new domain rules.

Historical Equipment keeps eighteen 72,000 YER rows from 15 August 2026 through
15 January 2028. Two Completed rows total 144,000 YER; sixteen Upcoming rows total
1,152,000 YER, with 15 October 2026 next. New approval of 100,010 YER over six
months retains 5,001 markup, 105,011 total, five 17,501 rows and one 17,506 row,
all Upcoming. Current rules and browser dates do not regenerate either snapshot.

## Complete browser sweep

All 357 unique production-screen cases have passing results across Chrome,
Firefox and WebKit, 119 per engine. All 21 new repayment-screen cases pass, as do
the six extended new-approval journeys. The final recheck run passes all 95
selected cases, leaving no unresolved failures.

The first queue completed 134 cases, including all Chrome cases, before stopping
at a checkpoint to reuse the browser capacity released by the API suite. The
six-worker continuation completed 128 more cases but encountered eleven WebKit
startup timeouts at the existing 30-second deadline and one Firefox interrupted
preparation retry that returned a session-expired result. That queue stopped
with six cases interrupted and 77 not yet run. Returning to three workers and
skipping the 262 passing cases verified all remaining 95 cases. No application
or test-source changes were needed for those rechecks. Earlier evidence images
regenerated by existing tests were restored to keep this slice focused.

Reproduce the checks with:

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:browser:api --workers=3 --timeout=120000
RIFD_WEBKIT_EXECUTABLE=/tmp/rifd-webkit-run.sh pnpm test:browser --workers=3 --timeout=120000
```
