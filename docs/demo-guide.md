# جرّب رِفد

[فهرس التوثيق](README.md) · [التشغيل محليًا](getting-started.md) · [الفيديو](demo/rifd-demo.mp4)

تستطيع استكشاف الموقع بأدوار افتراضية دون كلمات مرور. استخدم بيانات ومستندات تجريبية. بيانات كل متصفح وعنوان مستقلة، لذا يمكنك فتح ملف متصفح جديد لتجربة لا تغيّر عملك الحالي.

## اختر شخصية

| الشخصية | تجربة مناسبة للبدء |
| --- | --- |
| مريم سالم | استكمال المسودة `RIFD-2026-001`، أو مشاهدة الطلب الموافق عليه `005`. |
| هدى علي | فتح `004` وتجربة الاستجابة الخاصة لطلب التصحيحات. |
| عمر حسن | إنشاء طلب جديد واتباع الرحلة كاملة. |
| سلمى ناصر | قائمة الموظف، واستلام الطلبات وبدء المراجعة وتسجيل التقييم. |

خالد علي زميل افتراضي لتجربة نقل الإسناد، ولا توجد له هوية دخول. تبدأ البيانات بـ13 طلبًا، منها مسودة واحدة لا تظهر في قائمة الموظف. [الجرد التفصيلي](implementation/architecture.md#seed-inventory) مرجع اختياري.

## مسار قصير للمتقدم

1. ادخل باسم مريم، وقارن منتجات تمويل المخزون والمعدات.
2. افتح المسودة `001`، وأكمل البيانات والتمويل.
3. جرّب اختيار مستند، ومعاينة الملف الجاهز، ثم **حفظ التقدم**. أعد تحميل الصفحة لترى الفرق بين المختار والمحفوظ.
4. جرّب [فحص Jev](ai-features.md) إذا كنت تشغّل وضعه المحلي، أو افتح مثالًا محفوظًا موسومًا بوضوح.
5. راجع الطلب وأرسله بعد استكمال المطلوب. افتح التاريخ والملخص المطبوع.

## مسار قصير للمراجع والتصحيحات

1. غيّر الهوية إلى سلمى، وابحث في قائمة الطلبات وجرّب الفلاتر.
2. افتح طلبًا مقدمًا غير مسند، واستلمه، ثم ابدأ المراجعة. الاستلام وحده لا يغيّر الحالة.
3. عاين كل مستند وأكد فحصه قبل تقييمه. اقتراحات الذكاء الاصطناعي لا تؤكد الفحص بدلًا منك.
4. جرّب طلب تصحيح حقل أو مستند مع سبب محدد.
5. لتجربة جاهزة، ادخل باسم هدى وافتح `004`. صحّح المبلغ إلى `450000` واستخدم خطة الشراء البديلة، ثم احفظ الاستجابة الخاصة. لا تتغير النسخة المقدمة بعد.
6. أعد إرسال الاستجابة، ثم ارجع إلى سلمى لمراجعة التغييرات والتحقق منها وإعادة الفحوص المتأثرة.

الموافقة والرفض يحتاجان استيفاء شروطهما وسببًا وتأكيدًا. الطلب `005` يعرض قرارًا تاريخيًا وجدولًا افتراضيًا ثابتًا، ولا يثبت أنك سجلت قرارًا جديدًا خلال تجربتك.

## المستندات والتعافي

المستند التجريبي يجهز ملفًا من بيانات الطلب. قد تظهر أيضًا قائمة نماذج محفوظة للاختيار. هذه الملفات تختلف عن **العروض التوضيحية المحفوظة** لنتائج الذكاء الاصطناعي، التي لا تبدأ فحصًا جديدًا.

المرفقات تقبل PDF وJPEG وPNG حتى 5,000,000 بايت. اختيار اسم جديد للمحتوى نفسه لا يحقق تصحيحًا يطلب استبدال المستند. احتفظ بالعمل المحفوظ قبل تجربة الفشل أو إعادة الضبط.

| تجربة | ما الذي تراقبه؟ |
| --- | --- |
| طلبات بطيئة أو فشل الحفظ التالي | تظهر حالة انتظار واضحة، ويظل الملف السابق محفوظًا عند فشل الاستبدال. أعد المحاولة بإجراء صريح. |
| إنهاء الجلسة | تختفي المعلومات المحمية؛ ادخل بالهوية نفسها لفحص العمل الذي يمكن استعادته. |
| نقل الإسناد إلى خالد | يُرفض تعديل المراجع الذي يعتمد على نسخة قديمة؛ حمّل الأحدث وافحصه قبل إجراء جديد. |
| قطع الاتصال بعد جاهزية الموقع | يظل العمل المحلي المحمّل متاحًا. فحص Jev يحتاج اتصالًا، ولا يدعم المشروع بدءًا جديدًا دون شبكة. |
| إعادة ضبط العرض | اقرأ التحذير وأكد استبدال البيانات. يؤثر ذلك في جميع تبويبات العنوان نفسه. |

## مشاهد الفيديو

الجولة صامتة ومدتها 5:40، مع نصوص عربية وإنجليزية وانتقالات متلاشية بين المشاهد. تعرض نسخة محلية محدثة، وقد تختلف عن الموقع المنشور.

| الوقت | المشهد |
| --- | --- |
| 0:00 | التعريف بالمشروع. |
| 0:10 | المنتجات وخطوات الطلب. |
| 0:45 | إرفاق المستندات والحفظ والتعافي من الفشل. |
| 1:20 | فحص Jev الفعلي، والنتائج المختصرة، ونافذة موضع الحقل، والأمثلة المحفوظة. |
| 2:30 | المتابعة والإشعارات والطباعة. |
| 3:05 | قائمة الموظف واستلام الطلب وبدء المراجعة. |
| 3:40 | التقييم والتصحيحات والاستجابة الخاصة وإعادة الإرسال. |
| 4:15 | تعارض الإسناد والقرارات وصورة السداد الافتراضية. |
| 4:50 | اللغة والجلسة والصلاحيات وإعادة الضبط. |
| 5:25 | روابط الاستكشاف والتشغيل. |

يغيّر الفيديو الشخصية والطلب عمدًا لإظهار سيناريوهات مختلفة. لا تمثل جميع المشاهد مراحل متتابعة للطلب نفسه. يتضمن مشهد الذكاء الاصطناعي استدعاء Jev فعليًا واحدًا، وإعادة فتح نتيجته، وأمثلة محفوظة موسومة بوضوح.

[دليل التسجيل والتصدير بالإنجليزية](demo/README.md) يشرح إعادة إنتاج الفيديو. [قصة المشروع](case-study.md) تشرح القرارات التي يعرضها.
