## السجل والأدلة

[سجل المشروع](history.md) يربط الإصدارات والأبحاث ونتائج الاختبارات المؤرخة. هذه السجلات تشرح ما جرى في وقت محدد؛ الأدلة العملية أعلاه تصف طريقة استخدام المشروع الآن.

النسخة المحلية تتضمن تشغيل Jev الفعلي. إعداد الخدمة المستضافة منفصل، والكود الحالي يبقي إرسال طلبات Jev من الخدمة المستضافة معطّلًا. الفيديو يعرض النسخة المحلية المحدثة، ولا يعني نشرها على الموقع.
