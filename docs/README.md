## السجل والأدلة

[سجل المشروع](history.md) يربط الإصدارات والأبحاث ونتائج الاختبارات المؤرخة. هذه السجلات تشرح ما جرى في وقت محدد؛ الأدلة العملية أعلاه تصف طريقة استخدام المشروع الآن.

الفحص الفعلي باستخدام Jev متاح على الموقع المنشور، وكذلك في وضع التشغيل المحلي. [سجل النشر والتحقق](releases/2026-10-18.md) يوضح الاختبارات والنتائج الجزئية وحدودها. تسجيل الفيديو وبناء المشروع لا ينشران إصدارًا جديدًا تلقائيًا.
