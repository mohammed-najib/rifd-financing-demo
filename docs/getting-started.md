# تشغيل رِفد على جهازك

[فهرس التوثيق](README.md) · [English developer guide](development.md)

يمكنك تجربة الطلبات والمراجعة دون حساب مصرفي أو مفتاح ذكاء اصطناعي. تحتاج مفتاح TypeSafe فقط عند تشغيل فحص Jev الفعلي.

## التثبيت لأول مرة

ثبّت Node.js بإصدار 22.19 أو أحدث وpnpm بالإصدار 11.24.0، ثم نفّذ:

<div dir="ltr">

```sh
git clone https://github.com/mohammed-najib/rifd-financing-demo.git
cd rifd-financing-demo
npm install --global pnpm@11.24.0
pnpm install --frozen-lockfile
pnpm dev
```

</div>

افتح العنوان الذي يظهر في الطرفية، وعادةً يكون [http://127.0.0.1:5173](http://127.0.0.1:5173).

## اختر طريقة التشغيل

| الغرض | الأمر | العنوان الافتراضي |
| --- | --- | --- |
| تجربة الموقع وتطوير الواجهة | `pnpm dev` | `http://127.0.0.1:5173` |
| تشغيل الموقع مع فحص Jev الفعلي | `pnpm dev:jev` | `http://127.0.0.1:5174` |
| معاينة نسخة الإنتاج | `pnpm build` ثم `pnpm preview` | `http://127.0.0.1:4173` |

لإيقاف الخادم اضغط Ctrl+C في الطرفية. لكل عنوان ومنفذ بيانات مستقلة في المتصفح؛ الانتقال من 5173 إلى 5174 لا ينقل طلباتك المحفوظة بينهما.

### تشغيل Jev

أنشئ ملف `.env.local` في جذر المشروع، وضع مفتاحك فيه:

<div dir="ltr">

```dotenv
TYPESAFE_API_KEY=your_typesafe_api_key
```

</div>

ثم شغّل `pnpm dev:jev`. الملف مستثنى من Git، والمفتاح يبقى في عملية الخادم. لا تستخدم اسمًا يبدأ بـ `VITE_` للمفتاح. الطلبات الفعلية تُرسل إلى TypeSafe وقد تستهلك رصيد حسابك.

إذا لم تضف مفتاحًا، يحاول الأمر قراءة السر الموجود للمشروع الأصلي عبر Firebase CLI. هذا المسار يحتاج صلاحية على ذلك المشروع؛ عند تشغيل نسختك استخدم مفتاحك أنت. [تفاصيل الإعداد والحدود](development.md#local-jev-inference).

## أول تجربة

1. اختر **مريم سالم** من شاشة الهوية. الدخول افتراضي ودون كلمة مرور.
2. افتح مسودتها `RIFD-2026-001`، وتنقّل بين خطوات الطلب.
3. في المستندات، استخدم مستندًا تجريبيًا أو اختر ملفًا افتراضيًا من جهازك. ظهور اسم الملف يعني اختياره؛ **حفظ التقدم** هو ما يحفظه مع الطلب.
4. إذا شغّلت وضع Jev، افتح **فحص المستند**، وراجع المصدر والبيانات، ثم ابدأ الفحص. [شرح النتائج](ai-features.md).
5. احفظ العمل وأعد تحميل الصفحة للتأكد من استعادته.

لرؤية جانب الموظف، غيّر الهوية إلى **سلمى ناصر** وافتح قائمة الطلبات. [دليل التجربة](demo-guide.md) يقترح مسارات جاهزة للمراجعة والتصحيحات.

## إذا واجهت مشكلة

| المشكلة | ما الذي تجرّبه؟ |
| --- | --- |
| المنفذ مشغول | أوقف الخادم السابق أو استخدم `pnpm dev:jev --port 5180` لوضع Jev. |
| تعذّر تحميل مفتاح Jev | تحقّق من `TYPESAFE_API_KEY` في `.env.local`، ثم أعد تشغيل الأمر. |
| تعذّر بدء بيانات المتصفح | اسمح بالتخزين، وأغلق تبويبات العرض القديمة إن كانت تمنع الترقية، ثم اضغط إعادة المحاولة. |
| انتهت الجلسة | ادخل بالهوية نفسها لاستعادة العمل المسموح في التبويب الحالي. |
| تعذّر الفحص أو ظهرت نتيجة غير حاسمة | راجع المستند والصفحات المحددة. تظل المعاينة والحفظ متاحين؛ أعد المحاولة بإجراء صريح عند توفر الخدمة. |

توجد إعادة ضبط مؤكدة من واجهة الموقع. تستبدل بيانات العرض في جميع تبويبات العنوان نفسه، لذا احفظ ما تحتاجه أولًا. لا تحذف قاعدة بيانات استخدام Jev لتجاوز حد أو توقف محاسبي.
