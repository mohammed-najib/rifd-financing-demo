# السجل التاريخي والأدلة

[فهرس التوثيق](README.md)

تصف أدلة الاستخدام والتطوير النسخة الحالية من المشروع. أما الروابط هنا فتحفظ قرارات ونتائج تخص وقتًا أو إصدارًا محددًا، وقد تتضمن إعدادات قديمة أو مسارات ملفات محلية لم تعد موجودة.

## من أين جاءت النسخة الحالية؟

| المحطة | ما الذي تحفظه؟ |
| --- | --- |
| العرض الأصلي قبل Jev | [سجل التسليم](implementation/24-evidence.md) و[قائمة القبول الأصلية](acceptance/README.md)، بما فيهما الإصدار والقياسات وفحوص المتصفح. |
| إضافة مساعدة المستندات | [سير عمل Jev](implementation/jev-workflow.md)، و[الوصول وحدود الاستخدام](implementation/jev-live-access.md)، و[الإعداد المستضاف](implementation/jev-hosted-operation.md). |
| تشغيل Jev محليًا وتحسين المستندات | [سجل الاختبار المحلي](implementation/jev-local-development.md)، مع النتائج الإنجليزية والعربية وما لم تثبته. |
| تحديث الجولة المصورة | [بيانات الفيديو](demo/film.json) و[مراجعة التصدير](demo/review.json). مدة الجولة الحالية 5:40. |
| إزالة مجلد العمل المؤقت | أُزيلت `.scratch` ونسخ العمل التسع التي كانت بداخلها. بقيت الفروع والالتزامات في Git. |

## أين أجد التفاصيل؟

- [فهرس سجلات التنفيذ](implementation/README.md) يجمع الأدلة حسب الجزء الذي تختبره.
- [فهرس الأبحاث](research/README.md) يشرح المذكرات المؤرخة ومتى تُقرأ.
- [المتطلبات والتصميم الأصلي](acceptance/README.md#decision-and-design-provenance) محفوظان بروابط إلى التزامات محددة.
- [ملفات التخطيط القديمة في `.scratch`](https://github.com/mohammed-najib/rifd-financing-demo/tree/3983386c06f5ab7db68003f07f08ae0a6717d9b7/.scratch) متاحة في تاريخ Git، دون إعادتها إلى مجلد المشروع.
- [مقترحات المشاريع وسياق الاختيار القديم](https://github.com/mohammed-najib/rifd-financing-demo/tree/3983386c06f5ab7db68003f07f08ae0a6717d9b7/docs/project-options) حُذفت من التوثيق الحالي لأنها كانت بدائل قبل اختيار رِفد. [سياق البحث حينها](https://github.com/mohammed-najib/rifd-financing-demo/tree/3983386c06f5ab7db68003f07f08ae0a6717d9b7/docs/research).

قد تتضمن السجلات عبارة مثل «الإرسال معطّل» أو أعداد اختبارات وإصدارات متصفح. اقرأها مع تاريخها. للتشغيل الحالي استخدم [دليل البدء](getting-started.md)، وللفحص الفعلي استخدم [دليل Jev](ai-features.md).

ملفات الأدلة الخام تبقى كما سُجلت. وجود اختبار قديم ناجح لا يعني أن كل التعديلات اللاحقة مرت بالاختبار نفسه. كذلك، بناء المشروع أو تسجيل الفيديو لا ينشر إصدارًا جديدًا تلقائيًا على الموقع.
